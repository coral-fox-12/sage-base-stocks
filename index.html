Sage

Sage reads live Chainlink prices off Base mainnet — no API key, no exchange account — and writes a sourced research brief for each tokenized stock. Every number in the brief cites its feed. Every brief can be hashed and anchored onchain, so anyone can check it later.

Not financial advice. Research only — no real trading, no custody, no token launch. Tokenized stocks are not shares and carry no voting rights. Not available to US users for trading; this app does not trade.

Live prices

02

Research brief

One stock, one brief. Computed by fixed, auditable rules — 24h/7d change, volatility, momentum score 0–100. If a feed is stale (>25h), the score is withheld rather than guessed.

Onchain anchoring: contract ready, awaiting testnet deployment. The button stays disabled until then — we don't fake a transaction.
03

Paper portfolio

Virtual $10,000. Zero real money. Simulated trades at the live feed price. Positions are stored only in your browser (localStorage). Nothing here buys or sells anything real.

04

AI rewrite, optional

Paste a Gemini API key to have the brief rewritten in natural language. The key is stored only in your browser's localStorage and is never sent anywhere except Google's API. Without a key, the deterministic brief above is the full product — the agent works with zero keys.

05

How it works

No black box. The whole pipeline is three files you can read.

  1. Prices come from Chainlink aggregator contracts on Base (see js/feeds.js for the feed addresses).
  2. The brief is computed by fixed, auditable rules in js/analysis.js — 24h/7d change, volatility, momentum score 0–100. If a feed is stale (>25h), the score is withheld.
  3. Each brief can be anchored onchain as a hash (ResearchAnchor.sol) — deployed on Base Sepolia testnet, brief #0 (NVDA) already anchored.
  4. Built for the Base Stocks Maxxing Season, Agentic Stock Finance track. Full plan & verification notes.
